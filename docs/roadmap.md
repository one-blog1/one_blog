# 기능 로드맵

요구사항(`docs/requirements/`)을 Spec Kit 기능 단위로 나눈 목록이다. 기능 하나가 `/speckit-specify` → `/speckit-plan` → `/speckit-tasks` → `/speckit-implement` 한 사이클이고, 끝나면 `v0.{번호}.0` 태그를 붙인다 (constitution 개발 흐름).

- 001~007의 순서는 팀이 정했고, 008~015는 의존 관계에 맞춰 배치했다.
- spec·plan은 그 기능을 시작할 때 쓴다. 이 문서는 순서와 범위만 정한다.
- 테이블은 Crowfoot ERD "One Blog 메인블로그" 기준이고, 그 기능을 만들 때 마이그레이션으로 추가한다 (constitution IV).
- 순서나 묶음을 바꾸면 이 문서를 고친다. 요구사항 자체를 바꾸는 것이 아니므로 8장 기록은 필요 없다.

## 아직 번호가 없는 기능

- **블로그 정보 수정**: 이름·소개·대표 이미지 수정, 공개 범위·참여 방식 변경(비공개 전환 시 구독자 알림, D-37), 공유 링크 다시 만들기 (BLG-01, 2장 블로그장 표). 002 spec "후속 작업"에서 나왔다. 알림이 필요해 011 뒤가 자연스럽지만, 알림 없이 먼저 만들고 011에서 붙여도 된다. 번호를 정하면 위 표에 넣는다.

## 순서를 정한 이유 (008~015)

- **008 카테고리·태그**: 글(004) 바로 다음에 붙이는 작은 확장이고, 검색(010)의 태그 검색이 이것을 쓴다.
- **009 팔로우·구독·프로필**: 메인 피드(010)의 팔로우·구독 탭이 이것을 쓴다. 비밀번호 변경 시 다른 기기 로그아웃(SEC-04)도 회원정보 수정(USR-07)과 함께 여기서 한다.
- **010 검색·피드**: 태그(008)와 팔로우·구독(009)이 있어야 완성된다.
- **011 알림**: 알림을 보낼 기능(참여 승인 003, 댓글·좋아요 006, 공지 007, 팔로우 009)이 모인 뒤에 한꺼번에 연결한다. 이후 기능(012, 013)은 처음부터 알림을 붙인다.
- **012 블로그 운영**: 폐쇄·위임 알림이 필요해 011 뒤에 둔다. 04:00 배치와 `shedlock`을 여기서 만든다.
- **013 제재·신고**: 신고 처리 결과·정지 알림(011)과 폐쇄 배치(012)가 필요하다.
- **014, 015**: 다른 기능에 영향이 없어 마지막에 둔다. 일정이 밀리면 이 둘부터 2차로 미룬다.

## 의존 관계에서 주의할 점

- **002의 대표 이미지**: 블로그 대표 이미지(BLG-01)를 받으려면 파일 업로드가 필요하다. 002에서 `files` 테이블(`post_id`는 외래 키 없이)과 `FileStorage`(SCL-02), 형식·크기 검사(6.3)를 먼저 만들고, 005에서 글 이미지에 재사용하며 `files.post_id` 외래 키를 추가한다.
- **004의 카테고리**: ERD의 `posts.category_id`는 `categories`를 가리킨다. 004에서는 컬럼만 NULL로 두고, 008에서 `categories` 테이블과 외래 키를 추가한다.
- **007 관리자 1차 범위**: 신고(`reports`)와 제재(`sanctions`) 테이블은 013에서 만든다. 그래서 관리자의 신고 처리(ADM-04), 블로그장 경고·강퇴(ADM-07), 블로그 강제 폐쇄(ADM-02, 폐쇄 배치 필요)는 013에서 한다. 007은 조회·숨김·삭제·공지·통계·활동 기록과 관리자 로그인(D-98)까지다.
- **알림 연결 미루기**: 003, 006, 007, 009는 알림이 필요하지만 알림은 011이다. 각 기능의 spec "후속 작업"에 알림 연결을 적어 두고 011에서 붙인다.
- **04:00 배치**: 폐쇄(BLG-09), 30일 완전 삭제(4.5), 만료 Refresh Token 삭제(D-83)는 모두 같은 배치다. 012에서 만든다.
- **constitution II 1단계**: 회원(001) → 블로그(002, 003) → 게시판(004~006) 순서를 지킨다. 005(이미지)는 게시판 기능이라 1단계 안에 둔다.
