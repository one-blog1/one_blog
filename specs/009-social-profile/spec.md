# Feature Specification: 팔로우·블로그 구독·프로필·회원정보 수정

**Feature Branch**: `main` | **Created**: 2026-10-07 | **Status**: Draft

**Input**: "009 팔로우·블로그 구독·프로필·회원정보 수정 (SOC-01~03, USR-07, D-02, D-50)"

**관련 요구사항**: SOC-01, SOC-02, SOC-03, USR-07, SEC-02, SEC-04(비밀번호 변경 시 다른 기기 로그아웃), 6.3(프로필 사진), 6.5(닉네임), 6.6(한 번만·다시 누르면 취소), D-02, D-37, D-50, D-90

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 팔로우 (Priority: P1)

1. **Given** 다른 회원의 프로필, **When** 팔로우를 누르면, **Then** 팔로우되고 팔로워 수가 늘어난다. 다시 누르면 취소된다.
2. **Given** 프로필, **When** 팔로워·팔로잉을 누르면, **Then** 목록이 번호 페이지로 보인다 (SOC-02).
3. 자기 자신, 탈퇴한 회원, 관리자는 팔로우할 수 없고, 관리자 계정은 팔로우하지 않는다 (D-90).

### User Story 2 - 블로그 구독 (Priority: P1)

1. **Given** 볼 수 있는 블로그, **When** 구독하기를 누르면, **Then** 구독되고 내 블로그 화면의 "구독한 블로그"에 보인다. 다시 누르면 취소된다.
2. **Given** 일부 공개 블로그를 링크로 들어온 회원, **When** 구독하면, **Then** 그 뒤로는 링크 없이 들어올 수 있다 (D-50). 구독을 끊으면 다시 링크가 필요하다.
3. **Given** 비공개로 바뀐 블로그의 구독자(멤버 아님), **When** 들어가면, **Then** 볼 수 없지만 구독은 끊을 수 있다 (D-37).

### User Story 3 - 프로필 (Priority: P1)

1. **Given** `/users/{닉네임}`, **When** 열면, **Then** 닉네임·사진·소개·팔로워·팔로잉 수, 운영하는 블로그와 참여한 블로그가 보인다 (SOC-03).
2. 다른 사람에게는 전체 공개이고 숨기지 않은 블로그만 보인다. 본인에게는 모두 보인다.

### User Story 4 - 회원정보 수정 (Priority: P1)

1. **Given** 내 정보 화면, **When** 닉네임·전화번호·소개·프로필 사진을 바꾸면, **Then** 저장된다. 이메일과 이름은 바꿀 수 없다 (USR-07).
2. **Given** 현재 비밀번호를 맞게 넣고 새 비밀번호(SEC-02)를 두 번 넣으면, **Then** 바뀌고 이 기기를 뺀 다른 기기는 모두 로그아웃된다 (SEC-04).

### Edge Cases

- 다른 회원이 쓰는 닉네임·예약어는 거부(409). 동시에 같은 닉네임으로 바꿔도 `uk_users_nickname`이 하나만 남긴다.
- 프로필 사진은 본인이 올린 PROFILE 파일만. 바꾸거나 지우면 예전 파일은 삭제 표시한다.
- 팔로우·구독을 빠르게 여러 번 눌러도 회원 행 잠금으로 줄 세워 상태가 어긋나지 않는다.
- 트래픽 제한(6.6 "트래픽 제한 걸기")은 IP·회원별 요청 제한(015)에서 함께 건다.

## Requirements *(mandatory)*

- **FR-001**: 팔로우·구독은 누를 때마다 켜고 끈다(6.6). 결과로 지금 상태와 수를 돌려준다.
- **FR-002**: 일부 공개 블로그는 공유 링크(key)가 맞거나 그 블로그를 구독한 회원이면 볼 수 있다 (D-50).
- **FR-003**: 프로필 주소는 `/users/{닉네임}` (6.5).
- **FR-004**: 비밀번호를 바꾸면 지금 로그인(Refresh Token)을 뺀 나머지를 모두 폐기한다.
- **FR-005**: 관리자 계정은 팔로우·구독·프로필 수정을 하지 않는다 (D-90).

### Key Entities

- **팔로우(follows)**, **블로그 구독(blog_subscriptions)**: ERD 그대로. `users.profile_image_url`, `users.bio`를 엔티티에 매핑한다.

## Success Criteria

- **SC-001**: 비밀번호를 바꾼 뒤 다른 기기의 요청은 바로 401이 된다.
- **SC-002**: 프로필에서 남의 일부 공개·비공개 블로그 이름이 보이지 않는다.

## 후속 작업

- 팔로우·구독 알림(FOLLOW, BLOG_SUBSCRIBE)은 011에서 `FollowListener`, `SubscriptionListener`로 붙인다.
- 메인 피드의 팔로우·구독 탭(010).
- 차단 시 서로의 팔로우 해제(013, `FollowRepository.deleteBetween`).
