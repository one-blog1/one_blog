# Quickstart: SNS 공유 2차 확인

## 자동 (CI)

- `unit`: 공유 범위 판단 단위 테스트(`ShareScope`).
- `full`: `PostIntegrationTest`에서 공개·일부 공개·비공개·숨김 글의 `shareScope`, `PostShareE2ETest`(브라우저):
  1. 공개 블로그 글 → 공유 → 주소 칸(글 주소)·복사·X·텔레그램·페이스북이 보이고, 세 링크의 주소에 글 주소(인코딩)가 들어 있다. 기기 공유는 보이지 않는다(리눅스 Chromium).
  2. 같은 글에서 `navigator.share`를 가짜로 넣으면 기기 공유가 보이고, 누르면 제목·주소가 넘어간다.
  3. 복사 → "링크를 복사했어요." 안내.
  4. 비공개 블로그 글(멤버로 로그인) → 주소 칸·복사만 보인다.
  5. 일부 공개 블로그 글(key로 들어옴) → 주소 칸(key 포함)·복사만(가짜 `navigator.share`면 기기 공유도) 보인다.

## 운영에서 한 번 (배포 뒤)

1. 공개 글 → 공유 → X: 글쓰기 화면에 제목·주소, 올린 미리보기에 제목·이미지 (SC-002).
2. 페이스북·텔레그램도 같은 방식으로 확인.
3. 휴대폰 → 공유 → 기기 공유 → 인스타그램 DM으로 보내기 (SC-005).
