# Feature Specification: 카테고리·태그

**Feature Branch**: `main` | **Created**: 2026-10-07 | **Status**: Draft

**Input**: "008 카테고리·태그: 블로그별 카테고리 관리와 카테고리별 글 보기(BRD-03), 글 태그와 같은 태그의 글 보기(BRD-04, 6.4)"

**관련 요구사항**: BRD-03, BRD-04, 6.4, 6.1(태그 목록의 공개 기준), 2장(글 관리 권한), D-71, D-76, D-88

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 카테고리 관리 (Priority: P1)

1. **Given** 블로그장(또는 글 관리 권한을 받은 부블로그장), **When** 카테고리를 만들고 이름·순서를 바꾸면, **Then** 블로그 화면의 카테고리 줄에 그 순서로 보인다.
2. **Given** 카테고리, **When** 지우면, **Then** 그 카테고리의 글은 "분류 없음"이 되고 글은 그대로 남는다.
3. **Given** 일반 멤버나 다른 회원, **When** 카테고리를 만들거나 고치면, **Then** 거부된다.

### User Story 2 - 카테고리별로 보기 (Priority: P1)

1. **Given** 카테고리가 있는 블로그, **When** 글을 쓰며 카테고리를 고르면, **Then** 글 상세와 목록에 카테고리 이름이 보인다.
2. **Given** 블로그 화면, **When** 카테고리를 누르면, **Then** 그 카테고리의 글만 번호 페이지로 보인다 (D-76).
3. **Given** 다른 블로그의 카테고리 ID, **When** 글에 달려고 하면, **Then** 거부된다.

### User Story 3 - 태그 (Priority: P1)

1. **Given** 글쓰기, **When** `#Java`, ` 맛집 탐방 `, `java`를 태그로 넣으면, **Then** `java`, `맛집_탐방` 두 개로 정리돼 저장된다 (6.4).
2. **Given** 글 고치기, **When** 태그를 바꾸면, **Then** 예전 태그는 빠지고 새 태그만 남는다.
3. **Given** 태그 링크, **When** 누르면(`/tags/{태그}`), **Then** 같은 태그가 달린 글이 최신순 번호 페이지로 보인다 (BRD-04).

### Edge Cases

- 허용 문자가 아닌 태그, 정리 후 10개를 넘는 태그는 글 전체를 거부한다 (6.4).
- 태그 목록은 비회원도 보므로 전체 공개 블로그의 보이는 글만 보여준다. 일부 공개·비공개·숨긴·폐쇄 블로그와 숨김·삭제 글은 빠진다 (6.1과 같은 기준). 차단한 회원의 글 빼기는 차단 기능(013)에서 붙인다.
- 같은 이름의 카테고리는 한 블로그에 하나만(대소문자 무시). 카테고리는 블로그당 50개까지.
- 금칙어(6.4)는 보류라 하지 않는다.

## Requirements *(mandatory)*

- **FR-001**: 카테고리 이름은 앞뒤 공백을 뺀 1~30자.
- **FR-002**: 카테고리 관리는 블로그장과 글 관리 권한을 받은 부블로그장만 (2장, D-71). 권한은 요청마다 DB 멤버십으로 확인한다 (SEC-07).
- **FR-003**: 카테고리 목록은 블로그를 볼 수 있는 사람이면 누구나 보고, 카테고리별 글 수를 함께 준다.
- **FR-004**: 글 태그는 TagPolicy(블로그 태그와 같은 규칙)로 정리·검사하고 단 순서대로 보여준다.
- **FR-005**: 블로그 정보에 내 관리 권한(정보 수정·멤버 관리·글 관리)을 함께 줘서 화면이 관리 버튼을 보일지 정한다. 실제 권한 검사는 API가 한다.

### Key Entities

- **카테고리(categories)**, **글 태그(post_tags)**: ERD 그대로. `posts.category_id` 외래 키(ON DELETE SET NULL)를 이번에 추가한다.

## Success Criteria

- **SC-001**: 관리 권한 없는 계정으로 카테고리를 하나도 바꿀 수 없다.
- **SC-002**: 태그 목록에 전체 공개가 아닌 블로그의 글이 하나도 나오지 않는다.

## 후속 작업

- 통합 검색의 태그 검색(010)이 `post_tags`와 `PostCardService`를 다시 쓴다.
- 차단한 회원의 글 빼기(013).
