# Feature Specification: 메인 관리자 1차

**Feature Branch**: `main` | **Created**: 2026-10-07 | **Status**: Draft

**Input**: "007 메인 관리자 1차: 관리자 로그인(D-98), 회원·블로그 조회(ADM-01, 02), 글·댓글 숨김·삭제(ADM-03), 공지(BRD-10), 통계(ADM-05), 활동 기록(ADM-06, SEC-09). 신고 처리·블로그장 제재·강제 폐쇄는 013"

**관련 요구사항**: ADM-01, ADM-02(조회·숨김), ADM-03, ADM-05, ADM-06, SEC-09, SEC-11, BRD-10, 4.4(가리기·전체 보기 기록), D-44, D-90, D-94, D-98

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 관리자 로그인 (Priority: P1)

1. **Given** 운영자가 만든 관리자 계정, **When** 관리자 로그인 화면에서 관리자 아이디(예: admin01)와 비밀번호로 로그인하면, **Then** 관리자 화면에 들어간다 (D-98).
2. **Given** 관리자 계정, **When** 회원 로그인 화면(이메일)으로 로그인하면, **Then** 거부된다. 회원 계정도 관리자 로그인으로 들어올 수 없다 (SEC-09).
3. **Given** 관리자가 아닌 회원, **When** 관리자 API를 부르면, **Then** 거부된다.

### User Story 2 - 회원·블로그 조회 (Priority: P1)

1. **Given** 관리자, **When** 회원을 이메일·이름·닉네임으로 찾으면, **Then** 이메일·전화번호가 가려진 목록과 운영·참여 블로그 수가 보인다 (4.4).
2. **Given** 회원 상세, **When** "전체 보기"를 누르면, **Then** 원래 값이 보이고 누른 기록이 남는다 (4.4, ADM-06).
3. **Given** 관리자, **When** 블로그를 찾으면, **Then** 블로그장·멤버 수·글 수가 보인다 (ADM-02).
4. **Given** 문제 블로그, **When** 숨기면, **Then** 목록·검색에서 빠지고 멤버가 아닌 사람에게는 없는 블로그로 보인다. 풀면 돌아온다.

### User Story 3 - 글·댓글 숨김·삭제 (Priority: P1)

1. **Given** 어느 블로그의 글, **When** 숨기면, **Then** 목록과 상세에서 사라지고, 풀면 돌아온다 (ADM-03).
2. **Given** 글, **When** 지우면, **Then** 지운 주체가 관리자로 남는다(작성자 알림은 011). 관리자는 글을 고칠 수 없다 (D-07).
3. **Given** 댓글, **When** 숨기거나 지우면, **Then** 댓글 목록에서 사라진다.

### User Story 4 - 공지·통계·활동 기록 (Priority: P2)

1. **Given** 관리자, **When** 공지를 올리면, **Then** 메인 화면 위에 보이고 누구나 읽는다 (BRD-10).
2. **Given** 관리자, **When** 통계를 보면, **Then** 회원 수·블로그 수·글 수와 일별 가입·글 수가 보인다 (ADM-05).
3. **Given** 관리자 조치, **When** 활동 기록을 보면, **Then** 누가 언제 무엇을 했는지 보인다 (ADM-06).

### Edge Cases

- 관리자 계정은 회원가입 화면으로 만들 수 없다. 서버가 시작할 때 환경변수(ADMIN_LOGIN_ID, ADMIN_PASSWORD)로 한 번 만든다 (D-94).
- 관리자 검색어의 %, _는 글자 그대로 찾는다.
- 관리자는 회원을 정지·탈퇴시키지 않는다 (D-44).

## Requirements *(mandatory)*

- **FR-001**: 관리자는 관리자 전용 아이디로 관리자 로그인 화면에서만 로그인한다 (D-98, SEC-09).
- **FR-002**: `/api/admin/**`는 관리자만 쓸 수 있고, 역할은 요청마다 DB에서 확인한다 (SEC-11).
- **FR-003**: 회원 목록·상세의 이메일·전화번호는 서버가 가려서 보내고, 전체 보기는 기록을 남긴다 (4.4).
- **FR-004**: 블로그 숨김·풀기, 글·댓글 숨김·풀기·삭제, 공지 올리기·지우기, 개인정보 전체 보기는 모두 활동 기록(조치·대상·내용·IP·시각)을 남긴다 (ADM-06).
- **FR-005**: 숨긴 블로그는 목록에서 빠지고, 멤버가 아닌 사람에게 없는 블로그로 보인다.
- **FR-006**: 메인 공지는 블로그에 속하지 않는 글(MAIN_NOTICE)이고 누구나 읽는다 (BRD-10).
- **FR-007**: 통계는 최근 최대 90일의 일별 가입·글 수를 보여준다.

### Key Entities

- **관리자 활동 기록(admin_actions)**: ERD 그대로. 1년 보관(삭제 배치는 012).

## Success Criteria

- **SC-001**: 관리자가 아닌 계정으로 관리자 기능을 하나도 쓸 수 없다.
- **SC-002**: 관리자 조치는 빠짐없이 활동 기록에 남는다.

## 후속 작업

- 신고 처리 (ADM-04), 블로그장 경고·강퇴 (ADM-07), 블로그 강제 폐쇄 (ADM-02) → 013
- 관리자 글 삭제 시 작성자 알림, 공지 전체 알림 (3.6) → 011
- 활동 기록 1년 보관 후 삭제 (4.5) → 012
- 관리자 로그인 잠금·CAPTCHA (SEC-03, SEC-13) → 015
