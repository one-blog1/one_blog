# Feature Specification: 이미지 첨부·에디터

**Feature Branch**: `main` | **Created**: 2026-10-07 | **Status**: Draft

**Input**: "005 이미지 첨부·에디터 (BRD-05, 6.3, D-74, D-75). 글쓰기에 Toast UI Editor(마크다운)를 붙이고, 이미지를 붙이면 바로 올려 본문에 넣는다. 장당 3MB, 글 하나에 10장, 형식은 002의 업로드 검사를 그대로. 목록 썸네일은 첫 이미지. files.post_id 외래 키 추가"

**관련 요구사항**: BRD-05, SEC-08, SCL-02, 6.3, D-74, D-75

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 에디터로 글을 쓰고 이미지를 넣기 (Priority: P1)

1. **Given** 글쓰기 화면, **When** 열면, **Then** 마크다운 입력과 미리보기가 있는 에디터가 보인다 (D-74).
2. **Given** 에디터, **When** 이미지를 붙여 넣거나 끌어 놓으면, **Then** 바로 올라가고 본문에 이미지가 들어간다.
3. **Given** 3MB를 넘거나 허용하지 않는 형식, **When** 넣으면, **Then** 이유가 보이고 들어가지 않는다 (6.3).
4. **Given** 이미지 10장이 든 본문, **When** 한 장을 더 넣거나 저장하면, **Then** 10장까지라는 안내가 보인다.

### User Story 2 - 목록에서 첫 사진 보기 (Priority: P3)

1. **Given** 이미지가 있는 글, **When** 목록에서 제목에 마우스를 올리면, **Then** 첫 이미지가 작게 보인다 (6.3 썸네일).

### Edge Cases

- 본문에서 뺀 이미지는 글을 저장할 때 지운 것으로 표시된다 (4.5 30일 보관, 완전 삭제 012).
- 남이 올린 이미지 주소를 붙여도 내 글에 연결되지 않는다.
- 다른 사이트의 이미지 주소는 본문에 보이지 않는다 (읽는 사람의 IP가 다른 사이트로 새지 않게).
- 에디터 파일을 불러오지 못하면 글상자로 쓸 수 있다.

## Requirements *(mandatory)*

- **FR-001**: 글쓰기 화면은 Toast UI Editor(마크다운)를 써야 한다 (D-74).
- **FR-002**: 글 이미지는 jpg·jpeg·png·gif·webp, 장당 3MB이고 002와 같은 세 가지 검사(확장자·MIME·파일 앞부분)와 위치 정보 제거를 거쳐야 한다 (6.3, SEC-08).
- **FR-003**: 글 하나에 이미지는 10장까지다 (6.3).
- **FR-004**: 글을 저장할 때 본문에 있는 작성자 본인의 이미지를 그 글에 연결하고, 본문 순서를 기록해야 한다.
- **FR-005**: 목록은 글의 첫 이미지를 썸네일로 쓴다. 따로 줄인 파일은 만들지 않는다 (6.3 1차).
- **FR-006**: 본문에는 이 사이트에 올린 이미지만 보여야 한다.

## Success Criteria

- **SC-001**: 이미지를 넣고 저장하기까지 화면을 벗어나지 않는다.
- **SC-002**: 10장을 넘는 글이 저장되지 않는다.

## 후속 작업

- 연결되지 않은 이미지와 지운 이미지 완전 삭제 (4.5) → 012
- 비공개 블로그 이미지의 주소 접근 제한 (002 research R4 알려진 한계) → 이중화(S3) 때 서명 주소로 검토
