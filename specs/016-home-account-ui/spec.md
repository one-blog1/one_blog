# Feature Specification: 메인 홈·상단 메뉴·내 정보 정리

**Feature Branch**: `main` | **Created**: 2026-10-08 | **Status**: Draft

**Input**: "글씨는 검정 기반, 선택된 것만 색으로 현재 위치 표시 / 로고로 메인에 오면 참여 중인 블로그를 아이콘과 이름으로 / 공지 아래 내 블로그·메인 피드 버튼 / 오른쪽 위는 알림·닉네임·프로필 사진, 사진을 누르면 내 정보·설정·로그아웃 / 프로필 수정 전 비밀번호 재확인 / 회원 탈퇴는 내 정보 맨 아래 작은 빨간 글씨로, 들어가서 비밀번호 확인 / 회원가입 버튼 없애고 로그인 버튼만"

**관련 요구사항**: BLG-06, BRD-09, USR-03, USR-05, USR-07, SEC-04, 4.2(일관성·현재 위치 표시), D-100~D-104

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 메인 홈 "내 블로그" (Priority: P1)

1. **Given** 로그인한 회원, **When** 로고를 눌러 메인에 오면, **Then** 공지 아래에 [내 블로그][메인 피드] 버튼이 있고 "내 블로그"가 선택되어 참여 중인 블로그(내가 만든 것 포함)를 대표 이미지 아이콘과 이름으로 보여준다 (BLG-06, D-100). 대표 이미지가 없으면 블로그 색과 첫 글자 아이콘.
2. **When** [메인 피드]를 누르면, **Then** 글 피드와 블로그 둘러보기가 보이고 주소가 `/?view=feed`가 된다. 새로 고쳐도 그 화면이 유지된다.
3. 참여한 블로그가 없으면 "블로그 만들기"와 "메인 피드에서 둘러보기"를 안내한다. 목록 끝에는 "블로그 만들기" 아이콘, 위에는 "내 블로그 관리"(my-blogs.html) 링크.
4. 비회원과 관리자는 버튼 없이 메인 피드만 본다.

### User Story 2 - 상단 메뉴 (Priority: P1)

1. 비회원: 오른쪽 위에 "로그인" 버튼 하나. 회원가입은 로그인 화면의 링크로 (D-101).
2. 회원: 알림 종, 닉네임(내 프로필로), 프로필 사진 버튼. 사진을 누르면 내 정보·설정·로그아웃 순서의 메뉴가 열리고, 바깥을 누르거나 Esc를 누르면 닫힌다. 키보드로 쓸 수 있다.
3. 관리자: "관리자 화면" 링크와 로그아웃.

### User Story 3 - 프로필 수정 전 비밀번호 재확인 (Priority: P1)

1. **Given** 내 정보 화면, **Then** 이메일·이름·닉네임·전화번호·소개·프로필 사진을 보기만 한다. **When** [프로필 수정]을 누르면 비밀번호를 묻는다 (USR-07, D-102).
2. 맞으면 서버가 10분짜리 재확인 표시(서명한 HttpOnly 쿠키, 경로 `/api/me`, 지금 로그인과 묶임)를 주고, 그동안 프로필과 비밀번호를 바꿀 수 있다. 비밀번호 변경은 현재 비밀번호를 다시 묻지 않는다.
3. 재확인 없이 `PUT /api/me/profile`, `PUT /api/me/password`를 부르면 403 `REAUTH_REQUIRED`. 다른 기기(다른 로그인)의 재확인 표시는 쓸 수 없다.
4. 틀린 비밀번호는 회원당 10분에 5번까지 시도할 수 있다.

### User Story 4 - 설정과 회원 탈퇴 화면 (Priority: P2)

1. 알림 설정은 "설정"(settings.html)으로 옮긴다.
2. 내 정보 맨 아래에 작은 빨간 "회원 탈퇴" 링크 → withdraw.html에서 안내를 읽고 비밀번호를 넣어 탈퇴한다 (USR-05, D-103). 블로그장인 블로그가 있으면 그 목록과 막힌 이유를 보여준다(기존 규칙 그대로).

### User Story 5 - 현재 위치 색 (Priority: P2)

1. 글씨와 링크는 검정 기반. 선택된 탭·정렬·페이지 번호·메인 전환 버튼·메뉴처럼 "지금 여기"인 항목만 햇살 노랑으로 칠한다 (D-104). 주요 버튼은 검정 채움.

### Edge Cases

- 재확인 표시는 쿠키라 서버를 늘려도 그대로 동작한다(4.3). 비밀번호를 바꾸면 다른 기기 로그인이 끝나므로 그 기기의 표시도 쓸 수 없다.
- 로그아웃하면 재확인 표시도 지운다.
