# Quickstart: 소셜 간편 가입 확인

## 자동 테스트 (CI)

`feature/social-quick-signup`에 push하면 CI가 돈다. 확인할 테스트:

| 테스트 | 확인 내용 |
|---|---|
| SocialProfilesTest | 네이버 name·mobile·email(인증으로 봄), 구글 name, 카카오 email 인증 표시, `+82` 전화번호, 잘못된 값은 버림 |
| SocialNicknamesTest | 그대로 쓰기, 금지 글자 빼기, 너무 짧으면 `회원1234`, 겹치면 `길동2`, 12자 넘으면 줄이기 |
| SocialLoginIntegrationTest | `/pending`이 가린 값·need* 반환, 쿠키 값이 요청 값보다 우선, 빈칸이면 400, 동의 없으면 400, 같은 이메일이면 emailInUse·409, 이메일 없이 link 성공 |

## 운영에서 손으로 (배포 뒤)

준비: 카카오 개발자 화면 이메일 필수 동의(완료), 네이버 이름·휴대전화 제공 설정(완료), Redirect URI 등록.

1. 네이버로 처음 로그인 → 가입 화면에 가린 이메일·이름·전화번호, 네이버 별명이 닉네임 칸에 채워짐(고칠 수 있음), 다른 입력 칸 없음 → 동의 체크 → 가입하기 → 첫 화면에 로그인됨
2. 구글로 처음 → 휴대전화 칸만 → 가입
3. 카카오로 처음 → 이름·휴대전화 칸 → 가입
4. 이미 이메일로 가입한 주소의 소셜 계정 → "이미 가입한 계정이 있습니다" + 비밀번호 → 로그인되고, 내 정보에 연결 표시
5. 가입한 소셜 계정으로 다시 로그인 → 화면 없이 바로 로그인
6. 동의를 체크하지 않고 가입하기 → 동의해 달라는 안내
