# Feature Specification: 메인 공지에 사진 넣기

**Feature Branch**: `main` | **Created**: 2026-10-12 | **Status**: Draft

**Input**: "관리자가 공지에 이미지를 등록할 수 있게"

**관련 요구사항**: BRD-10, BRD-05, 6.3, 4.5, D-74, D-122, D-124

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 공지 에디터 (Priority: P1)

1. **Given** 관리자 화면 공지 탭, **Then** 공지 내용 칸이 블로그 글쓰기와 같은 Toast UI 에디터(마크다운, 미리보기)다. 에디터를 불러오지 못하면 지금처럼 글상자로 쓴다.
2. 사진을 붙여 넣거나 끌어다 놓거나 사진 단추로 고르면 바로 올라가고(`POST /api/files/post-image`) 본문에 들어간다. jpg·png·gif·webp, 한 장 3MB, 공지 하나에 10장 (6.3).
3. [수정]을 누르면 에디터에 원문이 채워지고, [취소]·탭 이동·저장 뒤에는 비워진다.

### User Story 2 - 사진 보관 (Priority: P1)

1. 공지를 저장하면 본문에 있는 사진을 그 공지에 연결한다. 연결된 사진은 "연결 안 된 사진 30일 뒤 삭제" 배치에서 빠진다.
2. 공지를 고칠 때 본문에서 빠진 사진, 공지를 지울 때 그 공지의 사진은 지운 것으로 표시해 30일 뒤 삭제된다 (4.5).
3. 처음 쓴 관리자와 지금 고치는 관리자가 올린 사진만 연결한다. 남이 올린 사진·다른 글에 연결된 사진은 연결하지 않는다.
4. 사진이 10장을 넘으면 400.

### Edge Cases

- 공지 본문은 지금처럼 서버에서 jsoup으로 거르고, 이 사이트에 올린 사진(`/files/...`)만 보인다.
