# Feature Specification: 메인 공지 개선 (수정·종류·목록·돌아가는 공지 줄)

**Feature Branch**: `main` | **Created**: 2026-10-12 | **Status**: Draft

**Input**: "관리자 화면에서 공지 수정할 수 있도록 공지 탭에서 삭제 왼쪽에 수정 버튼도 만들고 수정 기능 만들어줘", "공지 클릭 시 공지 내역 볼 수 있고 공지도 세분화 해줘 업데이트, 수정 등으로. 그리고 메인에서 공지 UI를 옆으로 나열하는 게 아니라 2초 있으면 다음 공지 타이틀로 넘어가고 이런 형식"

**관련 요구사항**: BRD-10, ADM-06, SEC-06, SEC-09, D-90, D-122(새로 정함)

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 관리자가 공지를 고친다 (Priority: P1)

1. **Given** 관리자 화면 공지 탭, **Then** 공지마다 [수정] [삭제]가 이 순서로 있다(수정이 삭제 왼쪽).
2. **When** [수정]을 누르면, **Then** 위 작성 칸에 그 공지의 종류·제목·내용(마크다운 원문)이 채워지고 버튼이 "수정 저장"으로 바뀌며 [취소]가 생긴다.
3. **When** "수정 저장"을 누르면, **Then** 공지가 바뀌고 활동 기록에 `NOTICE_UPDATE`가 남는다(ADM-06). 알림은 다시 보내지 않는다.
4. 고친 공지는 상세 화면에 "수정됨 · 고친 시각"이 함께 보인다.
5. 관리자가 아닌 회원·비회원이 수정 API를 부르면 403/401이다.

### User Story 2 - 공지 종류 (Priority: P1)

1. 공지는 일반·업데이트·수정·점검 중 하나다. 작성·수정 칸에서 고르고(기본 일반), 목록·상세·메인 공지 줄에 종류 이름표가 보인다.
2. 이미 올린 공지는 일반이 된다.
3. 정해진 값이 아니면 서버가 400 `VALIDATION_FAILED`로 거부한다.

### User Story 3 - 공지 목록과 내용 보기 (Priority: P1)

1. **When** 메인 공지 줄의 "공지" 이름이나 "전체 보기"를 누르면, **Then** 공지 목록 화면(`/notice.html`)이 열린다.
2. 목록은 [전체][일반][업데이트][수정][점검] 탭으로 거르고, 최신순, 페이지로 나뉜다.
3. 제목을 누르면 내용이 보이고, "목록으로"로 돌아간다(`/notice.html?id=…`).
4. 관리자 화면 공지 탭에서 제목을 눌러도 내용 화면이 열린다.

### User Story 4 - 메인 공지 줄 (Priority: P2)

1. 메인 위 공지 줄은 한 줄에 공지 하나(종류 이름표 + 제목)만 보이고, 2초마다 다음 공지로 넘어간다(최신 5개를 돈다). 하나뿐이면 넘기지 않는다.
2. 마우스를 올리거나 키보드로 공지에 들어가면 멈추고, 벗어나면 다시 돈다.
3. 움직임 줄이기 설정이면 효과 없이 글자만 바뀐다. 화면 읽기 프로그램에는 2초마다 읽어 주지 않는다(`aria-live="off"`).

### Edge Cases

- 수정 중에 다른 탭으로 가면 수정 상태를 버리고 작성 칸을 비운다.
- 지워진 공지를 수정하면 404 `NOTICE_NOT_FOUND`.
- 숨긴 공지는 목록·공지 줄에 나오지 않는다(기존).

## Requirements *(mandatory)*

- **FR-001**: `PUT /api/admin/notices/{id}` (관리자만) 제목·내용·종류 수정. 제목·내용 규칙은 작성과 같다(BRD-01).
- **FR-002**: `POST /api/admin/notices`에 `category`(생략 시 GENERAL).
- **FR-003**: `GET /api/notices?category=UPDATE` 종류로 거르기. 목록·상세 응답에 `category`, `categoryLabel`, 상세에 `updatedAt`, `edited`.
- **FR-004**: `posts.notice_category` (ERD v11, V18). MAIN_NOTICE만 값이 있고 다른 글은 NULL(`ck_posts_notice_category`).
