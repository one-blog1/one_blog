# Feature Specification: 내 블로그 새 글 블로그별 보기, 읽은 글 표시, 하트 좋아요

**Feature Branch**: `main` | **Created**: 2026-10-12 | **Status**: Draft

**Input**: "내 블로그의 새 글에서 (피드의 최신 글·인기 글처럼) 블로그를 고르면 해당 블로그의 새 글이 뜨게 / 읽은 글이 목록에 다시 있으면 글씨가 회색이 되는 등 읽었다는 걸 알 수 있게"

**관련 요구사항**: BLG-06, BRD-02, BRD-09, D-113, D-115, D-123

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 블로그 고르기 (Priority: P1)

1. **Given** 블로그에 참여한 회원의 메인 "내 블로그", **Then** "내 블로그의 새 글" 아래에 [전체]와 참여 중인 블로그 이름 단추가 피드 탭과 같은 모양으로 나온다. 순서는 위 블로그 아이콘과 같다(만든 블로그 먼저).
2. [전체]는 지금처럼 모든 블로그의 새 글을 시간순으로, 글마다 블로그 이름을 붙여 보여 준다.
3. 블로그를 고르면 그 블로그의 글 목록(`GET /api/blogs/{slug}/posts`, 공지 제외)을 보여 주고, 블로그 이름은 붙이지 않는다. 글이 없으면 "이 블로그에는 아직 글이 없어요".
4. 고른 단추는 이 기기에 기억해(localStorage, D-115와 같은 방식) 다음에 메인에 와도 그 블로그로 열린다. 기억한 블로그에서 나갔으면 [전체]로 연다.

### User Story 2 - 읽은 글 표시 (Priority: P2)

1. 글 화면을 열면 그 글 번호를 이 기기(localStorage)에 기억한다. 최근 1000개까지.
2. 모든 글 목록(메인·피드·블로그·검색)에서 기억한 글은 제목이 회색·보통 굵기, 사진이 흐려지고 제목 옆에 "읽음"이 붙는다. 서버에 저장하지 않아 기기마다 따로 센다.

### User Story 3 - 하트 좋아요 (Priority: P2)

1. 글 화면의 좋아요는 테두리와 "좋아요" 글자 없이 하트 아이콘과 숫자만 보인다.
2. 누르면 하트가 빨갛게 채워지고 숫자가 1 오른다. 다시 누르면 빈 하트로 돌아간다. 화면 읽기 프로그램에는 "좋아요, n개" / "좋아요 취소, n개"로 알린다.

### Edge Cases

- 블로그를 바꾸는 사이에 이전 응답이 늦게 오면 버린다.
- 그 블로그를 볼 수 없게 됐으면(정지 등) "이 블로그의 글을 불러오지 못했어요".
- 저장소(localStorage)를 못 쓰면 기억만 하지 않고 동작은 같다.
